# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please email security concerns to the Bakery Street Project organization administrators.

**Please do not create public GitHub issues for security vulnerabilities.**

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |

## Security Measures

This repository has the following security measures enabled:
- Dependabot vulnerability alerts
- Automated security fixes
- Branch protection on main
- Private repository (no public access)
- Proprietary licensing on sensitive code

## Disclosure Policy

We follow responsible disclosure practices. Please allow 90 days for vulnerability remediation before public disclosure.
