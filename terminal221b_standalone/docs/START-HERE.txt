Q: Do I need to change the original v1.0?
A: No! v2.0 is separate. v1.0 (Node.js) still works.
   This is a new Python-based v2.0 build alongside it.

Q: How long will development take?
A: 8 weeks total:
   - 2 weeks TUI
   - 2 weeks APIs
   - 2 weeks automation
   - 2 weeks polish/launch

Q: What's the performance target?
A: - <16 seconds per vulnerability analysis
   - 225+ targets per hour
   - <2 second response times
   - 99.9% uptime

Q: What's the primary LLM?
A: Cohete-7B (uncensored, fast, 7B params)
   But you can switch to any of 5 models with one click.

Q: Will it work on my system?
A: The engine auto-detects GPU/CPU/RAM and picks the best model:
   - GPU systems: Use GPU-accelerated models
   - CPU systems: Use CPU-optimized models
   - All run locally (no cloud)

Q: What do I do if I hit a blocker?
A: Read TERMINAL221B-V2-RESEARCH.md - it covers:
   - API specs for all platforms
   - Detailed architecture
   - Common pitfalls
   - Security considerations
